# DEWS · 이슬청년부

도원동교회 이슬청년부의 출석·돌봄·소그룹 관리 플랫폼. 현재는 가상 데이터 기반 UI 및 출석 흐름을 검증하는 첫 개발 단계입니다. 실제 운영용 인증·권한 제어·DB는 아직 연결되지 않았습니다.

## 실행

Node.js 22.12 이상 또는 호환되는 지원 버전과 pnpm을 사용합니다. 현재 Node 24 환경에서 개발합니다.

```sh
pnpm install
pnpm dev
pnpm test
pnpm build
```

기본 주소는 터미널에 표시되는 http://127.0.0.1:5173 입니다. 코드와 설치 의존성은 로컬에 저장됩니다. GitHub에는 커밋·푸시한 파일만 올라가며 node_modules, dist, 비밀 설정은 제외합니다.

## 현재 화면

- 공동체 홈: DEWS 민트/크림·청록 팔레트, 확장 카드, 공동체 소개, 예시 일정.
- 출석: 날짜 및 모임별 다중 선택, 확정 확인, 브라우저 저장, 수정 후 재확정.
- 돌봄: 가상 결석 대상 목록. 실제 개인 기록을 포함하지 않음.
- 행사·동아리: 예시 일정 목록과 상세 안내.
- 로그인: 연결 예정 안내만 제공. 가짜 로그인이나 인증 우회 기능은 없음.

실제 개인정보를 브라우저 미리보기에 입력하거나 저장하지 마세요. localStorage는 예시 출석 전용이며 실제 운영 저장 방식이 아닙니다.

## 환경

현재 작업 위치는 Windows의 OneDrive 문서 폴더입니다. WSL 파일시스템의 프로젝트가 아닙니다. OneDrive는 많은 의존성 파일을 동기화하면서 지연·충돌을 만들 수 있으므로 장기 개발 시 비동기화 폴더 또는 WSL의 홈 디렉터리를 권장합니다. 이 작업에서 폴더를 임의로 이동하지 않았습니다.

Docker는 추후 로컬 Supabase 검증에 사용합니다. 프런트엔드 실행에는 필요하지 않습니다. Windows와 WSL 사이에서 node_modules를 공유하지 말고 각 환경에서 다시 설치하세요.

## 디자인 참고

사용자 제공 템플릿의 넓은 여백, 둥근 카드, 청록색, 확장 카드 패턴을 반영했습니다. DEWS 채널 이미지의 민트·크림색과 글자 형태를 참고한 임시 텍스트 워드마크이며, 공식 로고 원본을 추출·대체한 파일은 아닙니다. 실제 행사나 예배 사진은 아직 제공되지 않아 코드 기반 그래픽을 사용했습니다. 유튜브 링크는 제공 이미지의 @dews518 핸들을 따릅니다.
