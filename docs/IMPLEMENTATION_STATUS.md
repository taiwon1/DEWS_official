2026-11-12 사용자 구현 시작 승인. 이 문서는 완료된 기능과 예정 기능을 구분한다.

## 첫 구현
- React / TypeScript / Vite / pnpm 프로젝트 구성.
- DEWS 브랜드를 참고한 반응형 홈, 출석, 돌봄, 행사 화면.
- 가상 출석 다중 선택·모임별 확정·브라우저 저장·재확정.
- 출석 미확정/결석 구분과 주간 출석 인정 규칙 단위 테스트.
- 실제 개인정보·운영 인증·DB 연동 없음. 모든 명단과 일정은 예시.

## 후속 UI 수정

## 익명 게시판 시연
- 게시판 메뉴, 제목·본문 작성, 공개 범위 선택·확인 후 등록, 목록·상세·검색·공개/비공개/내 글 필터.
- 가상 사용자(청년 A/B, 리더, 임원, 목회자) 전환으로 정책 검토. 작성 중 사용자 전환 금지.
- 모든 독자에게 익명 표시. 비공개 제목·본문·검색·건수는 UI에서 읽기 정책을 적용. 작성자·임원·목회자 허용, 리더 등 역할만으로 허용하지 않음.
- 시연 글은 App 메모리에서만 유지하며 새로고침 시 초기화. 실제 인증·서버·DB 접근 통제가 아니므로 개인정보 입력 금지 안내. 실제 데이터 저장/권한 기능 완성으로 간주하지 않는다.
- 운영 연결 시 서버가 검증한 세션/역할 사용, DB 접근 통제, 독자 응답의 작성자 ID 제외가 필수. 가상 계정 선택기는 운영에서 제거.
- 빌드 성공. 브라우저에서 비공개 작성 → 공개 범위 확인 → 익명 등록, 리더 전환 시 미노출, 임원 전환 시 열람 확인.
