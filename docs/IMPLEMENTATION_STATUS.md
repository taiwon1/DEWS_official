# 구현 현황

2026-11-12 사용자 구현 시작 승인. 이 문서는 완료된 기능과 예정 기능을 구분한다.

## 첫 구현
- React / TypeScript / Vite / pnpm 프로젝트 구성.
- DEWS 브랜드를 참고한 반응형 홈, 출석, 돌봄, 행사 화면.
- 가상 출석 다중 선택·모임별 확정·브라우저 저장·재확정.
- 출석 미확정/결석 구분과 주간 출석 인정 규칙 단위 테스트.
- 실제 개인정보·운영 인증·DB 연동 없음. 모든 명단과 일정은 예시.

## 후속 UI 수정
- 추상적 문구를 출석 체크·돌봄 대상·행사 일정 등 기능명으로 변경.
- 같은 페이지에서 예배·소그룹 두 열을 체크하고 선택한 모임을 함께 확정. 아직 진행하지 않은 모임은 확정 대상에서 제외 가능.
- 카드 확장·아이콘 전환, 버튼 화살표 반응, 일정 카드 상승 효과 복원.
- 모바일은 카드 세로 배치와 두 열 출석표 유지. 모션 감소 설정 존중.
- 빌드 및 기존 출석 테스트 4개 통과. 브라우저에서 카드 포커스 변경 시 확장 확인.
- 최신 미리보기: http://127.0.0.1:5173/ (개발 서버 실행 중에만 접근 가능).

## 다음 개발
1. 홈·출석 화면 사용자 검토 및 실제 브랜드/사진 원본 반영.
2. Supabase 로컬 환경, DB migration, 역할·기수·소속 및 기록 테이블 설계.
3. RLS와 역할별 부정 접근 테스트 후 인증·초대 연결.
4. DB 기반 출석·교육·회원 상태·돌봄 업무 구현.
5. 편성 알고리즘·예약 전환·데이터 인계 및 복구 검증.

무료 플랜을 사용한다. 유료 서비스·알림톡·실제 데이터 업로드·외부 배포는 이번 단계에서 수행하지 않는다.
