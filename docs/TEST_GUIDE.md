## 데이터에 준비된 사례

- `돌봄둘`, `돌봄넷`, `장후보`: 각각 2주·4주·26주 확인 대상.
- `최새봄`: 교육 완료, 첫 방문 6개월 미경과. 소그룹 배정 가능하지만 정회원 편입 불가.
- `윤새싹`: 교육 미완료. 서로 다른 1~4주차를 모두 기록해야 완료.
- `장결자`, `제적자`: 재적 복귀와 정회원 권리 회복을 분리해서 확인.
- 미확정 출석과 이전 소그룹 이력도 포함한다.

예약은 내일 이후 날짜로 시험한다. 실제 예약을 남기면 로컬 Docker가 켜진 상태에서 해당 날짜에 적용되므로 필요하지 않은 시험 예약은 취소한다. 자동 통합 테스트의 예약 전환 검사는 별도 rollback 데이터로 검증하여 기존 그룹을 유지한다.

새가족 초대 링크는 로컬 URL이므로 이 PC에서만 사용할 수 있다. 실제 운영 초대가 아니다. 변경한 비밀번호는 계정 seed 재실행으로 되돌리지 않는다.
