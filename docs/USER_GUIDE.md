# DEWS 사용설명서

로그인하면 할 수 있는 일만 메뉴에 나옵니다. 이름을 누르면 그 사람의 상세 창이 열립니다.

| 역할 | 어디서 무엇을 하나요? |
|---|---|
| 최고 관리자 | **인원 · 교육**에서 회원 상태나 계정 역할을 바꿉니다. 전체 출석, 돌봄, 소그룹, 일정도 관리합니다. 비공개 돌봄은 이 역할만 봅니다. |
| 임원 | **소그룹 편성**에서 인원을 배정합니다. **행사 · 동아리**에서 일정을 등록하거나 수정합니다. |
| 소그룹 리더 | **출석 체크**에서 내 그룹의 예배·모임 출석을 확정합니다. **돌봄 기록**에 만난 내용과 상태를 적습니다. |
| 새가족반 | **인원 · 교육**에서 새가족을 등록하고 1~4주차를 기록합니다. **돌봄 기록**에서 담당 새가족의 상태를 보고합니다. |
| 일반 청년 | **내 정보**에서 내 정보와 소그룹원 이름을 확인합니다. 일정과 게시판도 이용할 수 있습니다. |

- **상태 변경** · 최고 관리자가 인원 상세에서 변경 항목을 고르고 사유를 적어 저장합니다. 정회원 편입은 첫 방문 6개월과 교육 완료가 모두 필요합니다. 장결은 26주 연속 결석 확인이 필요합니다. 복귀와 정회원 권리 회복은 따로 처리합니다.
- **역할 변경** · 최고 관리자가 가입된 인원의 상세 창에서 **계정 역할 설정**을 엽니다. 역할을 여러 개 맡을 수 있습니다. 새 그룹 리더는 먼저 리더 역할을 받아야 출석을 입력할 수 있습니다.
- **출석** · 참석한 사람을 체크하고 **출석 인원 확인 → 확인 후 출석 확정**을 누릅니다. 확정 전에는 결석으로 기록되지 않습니다.
- **게시판** · 로그인한 사람은 글과 댓글을 남길 수 있습니다. 비공개 글은 작성자, 임원, 최고 관리자만 읽습니다.

**임원 지정** · 최고 관리자가 **임원 관리**에서 정회원을 체크하고 직책을 골라 저장합니다. 직책 체크를 모두 풀고 저장하면 임원 지정이 해제됩니다.

**새가족 등록** · 구성원 명단 오른쪽 위의 새가족 등록을 누릅니다. 인도자 이름과 특이사항은 선택 입력입니다. 등록 후 행을 누르면 최고 관리자와 담당 새가족반이 내용을 확인할 수 있습니다.
